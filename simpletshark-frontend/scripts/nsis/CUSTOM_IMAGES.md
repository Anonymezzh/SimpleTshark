# NSIS 自定义图片指南

## 📐 图片尺寸要求

### 1. 侧边栏图片（欢迎页和完成页）

**文件名：** `wizard.bmp`
**位置：** `scripts/nsis/images/wizard.bmp`
**尺寸：** **164 × 314 像素**
**格式：** BMP（24位 或 32位）
**用途：** 显示在欢迎页面和完成页面的左侧

**设计建议：**
- 使用你的品牌色作为背景渐变
- 可以放置你的 Logo（建议在顶部或中间）
- 可以添加产品截图或图标
- 保持简洁，不要太花哨
- 文字不要太多（因为会被安装向导的文字遮挡）

**示例布局：**
```
┌───────────────┐  164px
│               │  ↑
│   [Logo]      │  |
│               │  |
│               │  | 314px
│   [图标/截图]  │  |
│               │  |
│               │  ↓
└───────────────┘
```

---

### 2. 顶部横幅图片（安装路径选择等页面）

**文件名：** `header.bmp`
**位置：** `scripts/nsis/images/header.bmp`
**尺寸：** **150 × 57 像素**
**格式：** BMP（24位 或 32位）
**用途：** 显示在安装路径选择页、组件选择页等的顶部

**设计建议：**
- 横向渐变或纯色背景
- 可以在右侧放置小图标或 Logo
- 颜色要与侧边栏图片协调
- 通常是浅色背景

**示例布局：**
```
┌─────────────────────────┐  150px
│                  [Logo] │  ← 57px
└─────────────────────────┘
```

---

## 🎨 创建步骤

### 方法 1：使用 Photoshop 或 GIMP

1. 创建新图片：
   - **侧边栏**：164 × 314 像素
   - **横幅**：150 × 57 像素

2. 设计你的图片（添加渐变、Logo、图标等）

3. 保存为 BMP 格式：
   - Photoshop: 文件 → 导出 → 快速导出为 PNG，然后用画图打开另存为 BMP
   - GIMP: 文件 → 导出为 → 选择 BMP

4. 确保文件名正确：
   - `wizard.bmp`（侧边栏）
   - `header.bmp`（横幅）

5. 放到 `scripts/nsis/images/` 目录下

### 方法 2：使用在线工具

访问 [Canva](https://www.canva.com) 或 [Figma](https://www.figma.com)：

1. 创建自定义尺寸画布
2. 设计你的图片
3. 导出为 PNG
4. 用 Windows 画图打开，另存为 24位 BMP

### 方法 3：使用简单工具快速创建

使用 Windows 画图：

1. 打开画图
2. 调整画布大小（主页 → 调整大小 → 像素）
3. 填充颜色或渐变
4. 添加文字/图标
5. 保存为 24位 BMP

## ✅ 验证图片

创建图片后，在 Windows 上验证：

1. 右键点击图片 → 属性
2. 查看"详细信息"标签
3. 确认：
   - **尺寸**：164×314 或 150×57
   - **位深度**：24位 或 32位
   - **格式**：BMP

## 🎨 配色建议

### 现代简约风格：

**侧边栏（wizard.bmp）：**
- 背景：线性渐变 `#4A90E2` → `#357ABD`（蓝色）
- Logo：白色
- 点缀色：`#FFFFFF` 80% 透明度

**横幅（header.bmp）：**
- 背景：`#F5F8FA`（浅灰蓝）
- Logo：`#4A90E2`

**侧边栏（wizard.bmp）：**

- Logo：白色或亮蓝色

**横幅（header.bmp）：**
- 背景：`#2C3E50`

## 🔧 故障排除

### 问题 1：图片不显示

**原因：** 文件名或路径不正确
**解决：** 确认文件名是 `wizard.bmp` 和 `header.bmp`，且在 `scripts/nsis/images/` 目录下

### 问题 2：图片显示模糊或拉伸

**原因：** 尺寸不正确
**解决：** 确保精确使用 164×314 和 150×57 像素

### 问题 3：颜色显示不正确

**原因：** BMP 格式设置问题
**解决：** 使用 24位 BMP 格式，不要使用索引色

### 问题 4：中文文字显示为乱码

**原因：** 字体嵌入问题
**解决：**
- 不要在图片中直接添加中文文字
- 或者将文字转为路径/栅格化后再导出

---

## 📝 注意事项

1. **文件大小**：
   - 尽量控制在 500KB 以内
   - 使用 24位 BMP 而不是 32位可以减小文件大小

2. **兼容性**：
   - 使用标准的 Windows BMP 格式
   - 不要使用压缩的 BMP

3. **设计规范**：
   - 避免使用过于刺眼的颜色
   - 确保 Logo 和文字清晰可见
   - 考虑不同 Windows 主题（亮色/暗色）的兼容性

4. **自动回退**：
   - 如果没有找到自定义图片，会自动使用 NSIS 默认的 Metro 图片
   - 所以可以先测试效果，再添加自定义图片

## 🎯 快速开始

### 方法 1：自动缩放（推荐）✨

**不需要手动调整尺寸！脚本会自动帮你缩放。**

1. 准备你的原始图片（任意尺寸，PNG/JPG/BMP 都可以）
2. 命名为：
   - `wizard-original.png`（侧边栏图片）
   - `header-original.png`（横幅图片）
3. 放到 `scripts/nsis/images/` 目录
4. 在 Windows 上运行自动缩放脚本：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\resize-nsis-images.ps1
   ```
5. 脚本会自动生成正确尺寸的 `wizard.bmp` 和 `header.bmp`
6. 构建安装包：`npm run tauri-build-win`

### 方法 2：手动准备精确尺寸

1. 创建 `scripts/nsis/images/` 目录（已创建）
2. 设计或下载两张图片
3. 调整为正确尺寸（164×314 和 150×57）
4. 保存为 BMP 格式
5. 命名为 `wizard.bmp` 和 `header.bmp`
6. 放到 `scripts/nsis/images/` 目录
7. 重新构建安装包：`npm run tauri-build-win`

完成！🎉

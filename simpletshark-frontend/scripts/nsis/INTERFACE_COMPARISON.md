# NSIS 安装界面对比说明

## 你看到的"默认界面"是什么？

**重要说明：** 你现在看到的界面**已经是 Modern UI 2** 的界面，这就是 NSIS 的"现代化"外观。

## NSIS 三种界面风格对比

### 1. 经典默认界面（Classic UI）
如果你看到的是这种界面，那才是真正的"丑陋"默认界面：
- 灰色背景
- Windows 95 风格的按钮
- 没有侧边栏图片
- 非常简陋的文字显示
- 没有欢迎页和完成页

### 2. Modern UI 2 界面（当前使用）✅
这是我们已经配置的界面：
- 白色背景，现代化按钮样式
- **侧边栏有蓝色渐变图片**（欢迎页和完成页）
- **顶部有蓝色横幅**（安装路径选择页等）
- 专业的文字排版
- 标准的向导式流程
- 蓝色主题图标

### 3. 完全自定义界面
需要额外工作才能实现：
- 自己设计的品牌图片
- 完全自定义的颜色方案
- 可能需要使用 NSIS 皮肤插件

## 如何确认你用的是 Modern UI 2？

在安装程序中检查这些特征：

✅ **欢迎页面**
- 左侧有蓝色渐变的侧边栏图片
- 大标题 "Welcome to SimpleTshark Setup"
- 多行描述文字
- 如果看不到侧边栏图片，可能是 NSIS 版本太旧

✅ **目录选择页面**
- 顶部有蓝色横幅条
- 干净的白色背景
- 标准的浏览按钮

✅ **组件选择页面**
- 自定义对话框
- 复选框选项（桌面快捷方式等）

✅ **完成页面**
- 左侧有蓝色渐变的侧边栏图片
- "Launch SimpleTshark" 复选框
- "Visit SimpleTshark Website" 链接

## 为什么可能看起来"不够现代"？

Modern UI 2 的设计理念是**简洁专业**，而不是"花哨炫目"。这是刻意的设计选择：

1. **兼容性优先** - 在所有 Windows 版本上都能正常显示
2. **专业性** - 企业软件风格，不是消费软件风格
3. **可访问性** - 适合所有用户，包括老年用户和有视觉障碍的用户
4. **文件大小** - 不使用大量图片资源

## 如果你想要更"花哨"的界面

可以考虑以下方案：

### 方案 A：自定义品牌图片（推荐）
创建自己的品牌图片来替换 Metro 默认图片：
- **欢迎页侧边栏**: 164x314 像素，BMP 格式
- **标题栏横幅**: 150x57 像素，BMP 格式
- 可以使用你的品牌色、Logo、产品截图等

参考：README.md 中的"进一步自定义界面"部分

### 方案 B：使用第三方 NSIS 皮肤
一些可用的 NSIS 皮肤插件：
- **NSIS Modern User Interface (MUI2)** - 我们已经在用
- **nsisui** - 提供更多主题选项
- **InetC + Custom Pages** - 完全自定义 HTML/CSS 界面（复杂）

### 方案 C：使用其他安装程序制作工具
如果 NSIS 的风格真的不满意，可以考虑：
- **Inno Setup** - 另一个流行的开源安装程序制作工具
- **InstallForge** - 免费，有更现代的默认界面
- **Advanced Installer** - 商业软件，界面非常现代化

## 快速改进建议

如果你想让当前界面"看起来更现代"，最快的方法是：

1. **添加你的 Logo 图标** - 替换默认的蓝色图标
2. **创建自定义欢迎图** - 使用你的品牌色和 Logo
3. **调整颜色** - 修改 MUI_BGCOLOR 和 MUI_TEXTCOLOR

这些改动只需要 10-15 分钟，但效果会非常明显！
